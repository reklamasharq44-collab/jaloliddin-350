# Бесконечный путь — JALOLIDDIN 350

Браузерная 3D-игра/симулятор скоростного поезда на **three.js r128**. Один экран: вид из кабины машиниста, приборная панель, бесконечные маршруты.

Опубликовано как артефакт Claude (рабочая версия). Этот репозиторий — исходники и резервная копия.

## Запуск локально
Из этой папки:
    python -m http.server 8000
Открыть http://localhost:8000  (three.js грузится с CDN cdnjs — нужен интернет).

## Структура
- `index.html` — страница + поэтапный загрузчик модулей
- `style.css` — интерфейс кабины (панели, HUD, кнопки)
- `js/` — модули:
  - мир/рендер: `core.js`, `loop.js`, `atmos.js`, `track.js`, `trees.js`, `junction.js`
  - маршруты: `routes.js`, `route-forest.js`, `route-mountains.js`, `route-city.js`, `route-canyon.js`, `route-coast.js`, `route-under.js`, `depot.js`
  - поезд: `train.js`, `train-shape.js`, `train-materials.js`, `oncoming.js`, `chaser.js`
  - кабина/UI: `hud.js`, `cabpanel.js`, `controls.js`, `speed.js`, `toy.js`
  - физика/звук/эффекты: `physics.js`, `sound.js`, `warp.js`, `jet.js`, `cams.js`

## Управление
- Тяга/тормоз: `←`/`→` или `A`/`D` (позиции Э, Т, 0, 1–6)
- `Пробел` — экстренный тормоз · `R` — реверс · `E` — стрелка в депо · `H` — сигнал
- `C` — вид снаружи/из кабины · `V` или `1`–`6` — ракурсы внешней камеры
- `L` — день/ночь · `N` или `Shift` — нитро · `B` — сверхзвук (warp)

## Где остановились (нояб. 2026)
- Откатили рендер к состоянию версии 58 (bloom-свечение включено, повышенное разрешение) по просьбе — сравниваем ощущения.
- Починена кнопка «Заехать в депо» (не мигает, постоянный цвет).
- Фикс звёзд в сверхзвуке: гаснут у горизонта, не «растут из земли».
- Открытый вопрос: **bloom даёт лаги/мерцание на слабом ПК.** Варианты — лёгкое свечение только ночью, либо совсем без bloom + анизотропия и чуть ниже pixelRatio.
